# Tests

Folder ini menyimpan test lintas paket.

- `integration/` untuk test PostgreSQL, Redis, audit, dan RLS.
- `e2e/` untuk Playwright.
- `load/` untuk skenario k6.

Test unit tetap berada di dalam paket masing-masing. Folder ini tidak memiliki package.json sampai test lintas paket dibuat pada TASK-03.
