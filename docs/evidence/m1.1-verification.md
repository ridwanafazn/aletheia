## 5. Catatan dan Risiko

1. Service masih placeholder. Handler domain dimulai pada TASK-04.
2. `apps/web` belum memakai React atau Vite. Scaffold UI dimulai pada TASK-09.
3. `pnpm install --prod` di Docker memangkas dev dependency, tetapi belum diuji untuk service dengan dependency runtime seperti Express atau pg.
4. Build cache pnpm menggunakan BuildKit cache mount. CI perlu BuildKit aktif.
5. `.env` lokal dibuat dari `.env.example` dan tidak di-commit.
6. Stack Docker dihentikan setelah verifikasi untuk menjaga lingkungan bersih.
