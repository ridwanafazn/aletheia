## 2. Schema yang Dibuat

### Inti

- `enums.ts`: role, policy, claim, payroll, payment, report, audit.
- `primitives.ts`: UUID, uang desimal, rate, tanggal, periode, cursor, idempotency, NIK, rekening, masking.
- `errors.ts`: 17 error code dan pemetaan HTTP status.
- `api.ts`: envelope sukses/gagal, pagination meta, generic response.
- `auth.ts`: login, refresh, MFA, user summary, auth context.

### Domain

- `policy.ts`: `CLAIMS_POLICY`, `PAYROLL_TAX_POLICY`, create/approve/publish, validasi level approval, dokumen wajib, PTKP, TER, BPJS, JKK, komisi, dan bracket tahunan.
- `claims.ts`: draft, revisi, submit, keputusan, upload signature, detail, dokumen, anomali, audit, pencairan, payment.
- `payroll.ts`: employee, sales achievement, attendance, leave, batch, item, breakdown, payslip, report, reconciliation, payment.
- `payments.ts`: payment intent, create request, webhook event.

### Payments Package

- `PaymentProvider` interface.
- `MockPaymentProvider` dengan idempotency, konflik entity, auto-complete, reverse, dan webhook.
- Error class: `PaymentConflictError`, `PaymentNotFoundError`, `PaymentStateError`.

## 3. OpenAPI

Artifact: `packages/shared-contracts/openapi.json`.

- OpenAPI 3.1.0.
- 13 path utama.
- 29 komponen schema.
- Security scheme bearer JWT.
- Envelope sukses dan gagal.
- Path mencakup auth, claims, upload signature, payroll batch, approve, disburse, reports, policies, employees, payslips.

- `BranchKpiSummary`, `AnomalyFlagView`, `AuditTrailEntry`, `ClaimAuditDetail`, `WhatIfSimulationResult`.

## 5. Catatan dan Risiko

1. OpenAPI mencakup 13 path inti, belum seluruh endpoint HRIS dan payment webhook.
2. GraphQL SDL masih statis. Validasi SDL terhadap resolver dilakukan pada TASK-08.
3. Contoh tabel TER tetap dipotong. Validator hanya memastikan bracket terakhir mencakup 100 miliar dan tarif minimal 15 persen. Tabel resmi lengkap wajib diverifikasi konsultan pajak.
4. Test fixture dikecualikan dari build agar tidak masuk artefak produksi.
5. `pnpm verify` menjalankan test source, bukan duplikat dari `dist`.
6. Endpoint runtime dan database belum dibuat. TASK-04 dan TASK-05 berikutnya.
