## 2. Instrumentasi

Paket baru `packages/observability` menyediakan:

* `initTelemetry` dengan OTLP HTTP exporter untuk trace dan metric.
* Sampling parent-based, rasio 1 untuk lokal dan dapat diatur lewat `OTEL_TRACES_SAMPLER_ARG`.
* Instrumentasi HTTP, Express, pg, dan pino.
* Middleware metric HTTP dengan route ternormalisasi.
* `withSpan` untuk span domain.
* `registerPoolMetrics` untuk gauge pool database.
* `currentTraceFields` untuk korelasi log.

Service memuat `dist/instrumentation.js` sebelum aplikasi melalui `node --import`. Dockerfile Express memakai Node 24 dan preload yang sama.

Span yang terverifikasi:

* `http.server` dan `GET` pada service Express.
* `pg.query` dan `pg.connect`.
* `audit.append`, `queue.publish`, `payment.call`, `claim.decision`.
* `http.server`, `queue.consume`, `payroll.batch` pada Go worker.

Edge gateway membuat `traceparent` W3C, meneruskannya ke service, mencatat `trace_id` pada access log, dan mengembalikan `x-trace-id`.

## 9. Batasan

* QStash token tidak tersedia. Skenario payroll mengirim event bertanda tangan langsung ke worker dengan `ALLOW_UNSIGNED_EVENTS=true`. Produksi wajib memakai QStash dan signature.
* Edge tidak mengekspor span OTLP sendiri karena berjalan di Cloudflare Workers. Edge membuat dan meneruskan `traceparent`, mencatat trace ID, dan trace dimulai di service pertama. Jika dibutuhkan, edge span dapat ditambahkan dengan exporter OTLP ringan di TASK-18.
* RUM LCP dan INP belum diinstrumentasi. Web SLO diukur dari bundle, TTFB, DOMContentLoaded, dan CLS lokal.
* Service demo masih memakai role pemilik database. RLS sudah diverifikasi pada M5.1; pengikatan tenant per transaksi tetap prasyarat production di TASK-18.
