## 6. Batasan dan Risiko

* Token QStash belum aktif. Event live dikirim manual; pipeline publish tetap diuji unit test M3.1.
* `U-20` dan `I-09` membutuhkan payslip PDF dan rekonsiliasi tahunan. Keduanya dijadwalkan di TASK-11 dan tidak diklaim selesai di sini.
* Handler belum menandai batch `FAILED` saat error permanen. QStash akan mencoba ulang; retry, `PARTIAL`, dan rekonsiliasi payment masuk TASK-12.
* Batch `THR` dan `THIRTEENTH_MONTH` ditolak sampai formula khusus tersedia. Ini mencegah pembayaran THR dihitung sebagai gaji reguler.
* Event `PAYSLIP_GENERATE`, `REPORT_GENERATE`, `PAYMENT_RECONCILE`, dan `AUDIT_VERIFY` sengaja mengembalikan `500` agar tidak diakui sebagai selesai. Implementasinya berada di TASK-11, TASK-12, dan TASK-15.
* What-If saat ini hanya menerima override `agent_commission_tiers` dan `commission_mode`. Override policy lain ditolak agar simulasi tidak menyesatkan.
* Overtime rest day belum dihitung terpisah karena ringkasan absensi hanya menyimpan total jam lembur.
* Refresh MV bersifat global, bukan per tenant. Ini operasi sistem, bukan endpoint pengguna.
* Worker belum menetapkan `app.tenant_id` per transaksi. Semua query memfilter `tenant_id` eksplisit, tetapi RLS defense-in-depth untuk worker masuk TASK-15.
* Worker live berjalan sebagai container lokal `aletheia-worker-m32-test` di port 4014 dan bergantung pada PostgreSQL lokal.
* Semua perubahan belum di-commit atau di-push.
