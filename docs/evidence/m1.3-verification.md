## 2. Skema

Empat skema dan 23 tabel:

- `governance`: tenants, branches, users, policy_versions, audit_logs, refresh_tokens, mfa_recovery_codes.
- `claims`: submissions, documents, approval_steps, disbursements.
- `payroll`: personnel, sales_achievements, batches, items, attendance_summaries, leave_requests, payslips, tax_reports, tax_reconciliations, payments.
- `analytics`: anomaly_flags, what_if_simulations.

Kolom uang memakai `NUMERIC(18,2)`. Persentase memakai `NUMERIC(7,4)`. Waktu memakai `TIMESTAMPTZ`. Primary key UUID dibuat aplikasi, kecuali `audit_logs.id` memakai `BIGSERIAL`.

## 3. RLS

- 22 tabel tenant-scoped memakai policy `tenant_isolation`.
- Policy memakai `current_setting('app.tenant_id', true)::uuid`.
- `governance.tenants` adalah root dan tidak memakai RLS.
- `analytics.mis_monthly_kpi` adalah materialized view dan tidak memakai RLS.
- Akses KPI melalui `analytics.v_mis_monthly_kpi` dengan `security_barrier`.
- Probe menunjukkan SAU hanya melihat 3 cabang, BPUI hanya 1 cabang dan 0 klaim.

## 4. Audit Chain

- `governance.append_audit_log` memakai `SECURITY DEFINER`, advisory lock per tenant, canonical JSONB, dan SHA-256.
- `governance.prevent_audit_mutation` memblokir update dan delete.
- Role aplikasi hanya mendapat `EXECUTE` pada fungsi audit, bukan DML langsung.
- Tiga baris seed membentuk chain:

```text
id 1 prev 000000000000 hash ea1ace8131eb
id 2 prev ea1ace8131eb hash f45c0bb78491
id 3 prev f45c0bb78491 hash 386776c0677b
```

## 6. Catatan dan Risiko

1. Verifikasi memakai PostgreSQL lokal, bukan Neon. Koneksi Neon dan branching belum diuji.
2. Seed memakai policy contoh. Tabel TER masih dipotong dan wajib diverifikasi konsultan pajak.
3. `tax_reconciliations` seed berstatus `DRAFT` karena posting selisih belum memiliki batch koreksi.
4. Role `aletheia_app` dan `aletheia_readonly` dibuat oleh migrasi lokal. Di Neon, pembuatan role perlu penyesuaian izin.
5. Role `aletheia_app` tidak dapat menulis ke `governance.tenants`; migrasi 0002 mencabut DML tenant root.
6. Endpoint runtime belum ada. TASK-04 dan TASK-05 berikutnya.
7. `docker compose --profile local-db up -d postgres` disediakan untuk lokal. Neon tetap target produksi.

## 7. Perintah Reproduksi

```bash
docker compose --profile local-db up -d postgres
cp .env.example .env
pnpm db:migrate
pnpm db:seed
pnpm db:check
```
