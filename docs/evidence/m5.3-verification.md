## 3. Perintah E2E

```bash
cd apps/web
RUN_FULL_E2E=1 WORKER_URL=http://127.0.0.1:4004 \
  node node_modules/@playwright/test/cli.js test
```

Atau dari root:

```bash
pnpm test:e2e
pnpm test:a11y
```

`RUN_FULL_E2E=1` mengaktifkan alur payroll lengkap. Tanpa flag tersebut, test payroll lengkap di-skip dengan alasan eksplisit agar mesin tanpa worker tetap dapat menjalankan suite dasar.

## 8. Flaky Policy

* E2E memakai `workers: 1` karena database, akun seed, dan batch payroll dipakai bersama.
* Tidak ada retry pada konfigurasi Playwright.
* Test membuat data sendiri dengan suffix unik dan idempotency key unik.
* Test payroll membuat batch koreksi dengan `correction_seq` berikutnya, menghitung lewat worker, lalu menyetujui dan mencairkan.
* Test komplain memilih klaim konflik tanpa review melalui API, bukan mengandalkan urutan tabel.
* Test klaim seed memakai ID deterministik.
* Suite penuh dijalankan dua kali berturut-turut tanpa flaky.

Test legacy `payroll-approval.spec.ts` dihapus dan digantikan oleh alur payroll mandiri di `final-qa.spec.ts`.
