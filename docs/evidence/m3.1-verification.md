## 3. Kontrol Keamanan dan Finansial

- **Policy binding.** Batch menyimpan `policy_version_id` aktif saat dibuat. Kalkulasi nanti membaca versi ini, bukan policy aktif terbaru.
- **PII.** NIK dan rekening hanya disimpan sebagai hash SHA-256 dengan pepper dan bentuk masked. Respons serta audit tidak memuat nilai mentah.
- **Idempotency.** Create batch, approval, disbursement, payslip request, dan report memakai `Idempotency-Key`. Replay mengembalikan data tersimpan dengan `X-Idempotent-Replay: true`.
- **I-13.** Unique `(tenant_id, batch_id, personnel_id)` menolak item ganda.
- **I-14.** Batch dikunci `FOR UPDATE NOWAIT`. Hanya batch `APPROVED` yang dapat dicairkan. Partial unique index dan state `DISBURSING` mencegah dua request membuat payment aktif kedua.
- **SoD.** Pembuat batch tidak dapat menyetujui. Anggota personel tidak dapat memutuskan cutinya sendiri bila akun pengguna tertaut.
- **Audit.** Setiap mutasi penting menulis audit di transaksi yang sama.
- **QStash.** Kalkulasi mengirim tepat satu event coarse-grained per batch. Payslip dan report memakai event terpisah.
- **Payment.** `packages/payments` mock dipakai per item. Status `PAID` hanya berasal dari respons provider.

## 6. Catatan dan Risiko

1. Kalkulasi belum diimplementasikan. Batch akan tetap `CALCULATING` sampai TASK-07 mengisi item dan status `READY_FOR_APPROVAL`.
2. QStash token belum dikonfigurasi pada demo. Unit test memverifikasi tepat satu pesan dengan fake fetch, tetapi worker belum menerima event nyata.
3. Payslip request hanya membuat event dan metadata. Baris payslip final serta PDF menunggu TASK-11 dan worker.
4. Report request hanya membuat baris `QUEUED`. File, checksum, dan status `READY` menunggu worker dan TASK-11.
5. Retry payment `FAILED` dengan attempt berikutnya belum diimplementasikan. Batch `PARTIAL` belum memiliki endpoint retry. Ini masuk TASK-12.
6. Webhook payment payroll belum ada. Mock auto complete menutup demo lokal.
7. Rekonsiliasi PPh 21 tahunan belum diimplementasikan. Ini TASK-11.
8. Tenant-wide report dengan `branch_id NULL` belum memiliki unique index efektif karena perilaku NULL pada unique constraint. Perlu partial unique index di hardening.
9. Payroll UI, payslip UI, dan report UI belum dibangun.
10. Neon, Koyeb, Render, Upstash, dan Cloudinary produksi belum dikonfigurasi.
