## 2. Edge Gateway

| Area | Implementasi |
| --- | --- |
| Runtime | Cloudflare Workers, Hono, `wrangler` |
| Autentikasi | Verifikasi EdDSA access token dengan `jose`, issuer dan audience tetap |
| REST proxy | `/api/v1/auth`, policies, audit ke governance; claims ke claims-service |
| HMAC | `HMAC-SHA256(method:path:bodySha256:userId:role:branchId:tenantId:timestamp)` |
| Body integrity | Hash byte body asli, path dan query dipisahkan |
| Rate limit | Upstash REST bila tersedia, fallback memori per isolate |
| CORS | Origin allowlist, credentials aktif, preflight 204 |
| Cookie | `SameSite=Strict` di dev, ditulis ulang menjadi `SameSite=None; Secure` untuk preview lintas situs |
| GraphQL | Yoga, tiga query, scalar DateTime, Decimal, JSON |
| Kedalaman query | Maksimal 4, ditolak sebelum eksekusi |
| Introspeksi | Dinonaktifkan pada production |
| BFF | Cache promise per request, jumlah panggilan upstream diekspos pada header |
| Keamanan | Stack trace tidak dikirim ke browser, error internal disamarkan |

## 4. Preview Live

- Web dibangun dengan `VITE_API_BASE_URL` menuju Worker dan `VITE_DEMO_UPLOAD=true`.
- Pages memakai `_redirects` untuk fallback SPA dan `_headers` untuk header keamanan.
- Worker memakai secret `INTERNAL_GATEWAY_SECRET` dan `JWT_PUBLIC_KEY`, serta origin Pages.
- Login lintas origin berhasil. Cookie refresh terkirim sebagai `SameSite=None; Secure` dan aplikasi bertahan setelah reload.
- Live API flow berhasil membuat klaim `CLM-SAU-202611-729078`, submit, approve, dan disburse sampai `PAID`.
- GraphQL live mengembalikan KPI `BDG-01` dan satu simulasi What-If.

**Batasan preview:** service governance dan claims berjalan di mesin lokal dan diekspos melalui dua Cloudflare quick tunnel. Preview tetap hidup selama proses lokal dan tunnel berjalan. Neon dan deployment permanen Koyeb atau Render belum dikonfigurasi. Ini adalah preview demo, bukan staging.

## 7. Catatan dan Risiko

1. Rate limit memakai memori per isolate karena Upstash belum dikonfigurasi. Pada beberapa isolate, batas efektif dapat berlipat.
2. Service backend preview bergantung pada tunnel sementara dan komputer lokal.
3. Neon belum diprovision; data preview memakai PostgreSQL lokal.
4. `VITE_DEMO_UPLOAD=true` pada preview membuat lampiran sintetis. Produksi wajib memakai Cloudinary nyata.
5. GraphQL BFF saat ini melayani tiga query kontrak. Query payroll dan MIS lanjutan menunggu TASK-07 dan TASK-10.
6. Playwright belum masuk pipeline CI. Gate E2E dijalankan lokal.
7. Worker bundle 326 KB gzip masih jauh di bawah batas free tier, tetapi Yoga menambah ukuran. Optimasi dapat dilakukan pada TASK-15.
8. Preview URL Worker memakai domain `workers.dev`, bukan custom domain. CSP belum diterapkan pada Worker.

## 8. Perintah Reproduksi

```bash
node scripts/generate-dev-keys.mjs
docker compose --profile local-db up -d postgres
pnpm db:migrate
pnpm db:seed

pnpm --filter @aletheia/governance-service build
pnpm --filter @aletheia/claims-service build
node services/governance-service/dist/index.js
node services/claims-service/dist/index.js

pnpm --filter @aletheia/edge-gateway dev
pnpm --filter @aletheia/web dev

pnpm --filter @aletheia/edge-gateway test
pnpm --filter @aletheia/web test
pnpm --filter @aletheia/web e2e
pnpm --filter @aletheia/web build
```

Deploy preview:

```bash
VITE_API_BASE_URL=https://aletheia-edge-preview.ridwanafzn.workers.dev \
VITE_DEMO_UPLOAD=true \
  pnpm --filter @aletheia/web build

pnpm --filter @aletheia/edge-gateway exec wrangler deploy
pnpm --filter @aletheia/edge-gateway exec wrangler pages deploy ../web/dist \
  --project-name aletheia-web-preview \
  --branch main
```
