## 2. Dashboard MIS

Route `/mis`:

* Filter periode, cabang, dan rentang tren 3, 6, atau 12 bulan.
* Empat KPI utama: klaim diajukan, nominal klaim disetujui, payroll dicairkan, dan PPh 21.
* Empat metrik sekunder: approval rate, turnaround, utilisasi anggaran, dan variance MoM.
* Tabel KPI per cabang dengan tautan drill-down ke `/claims` dan `/payroll`.
* Grafik tren klaim dan payroll dengan ringkasan teks.
* Tabel data alternatif di dalam elemen `details`.
* Kartu mobile untuk tabel cabang.
* Empty state, loading skeleton, dan error state dengan correlation ID.

Data berasal dari `analytics.v_mis_monthly_kpi` melalui GraphQL `misExecutiveSummary` dan `misTrend`.

## 3. What-If Sandbox

Route `/mis/what-if`:

* Memuat kebijakan payroll aktif dan tarif komisi.
* Form nama simulasi, periode historis, cabang, dan penyesuaian tarif komisi.
* Pratinjau tarif aktif versus tarif simulasi per tier.
* Mutation `runWhatIfSimulation`.
* Banner `enqueued=false` ketika token QStash belum aktif.
* Perbandingan aktual, simulasi, selisih biaya, variance, kebijakan dasar, dan impact breakdown.
* Daftar simulasi terakhir untuk memilih pembanding.
* Badge `SIMULATION READ ONLY` dan copy bahwa data produksi tidak berubah.

Data seed simulasi kenaikan komisi 50 persen tampil sebagai pembanding.

## 5. Catatan

* Tombol dan mutation What-If memerlukan token QStash untuk diproses worker. UI menampilkan status antrean secara jujur.
* Grafik hanya menampilkan bulan yang tersedia pada materialized view. Seed saat ini memiliki satu bulan.
* Drill-down klaim memakai filter `branch_id`, `from`, dan `to` yang diteruskan ke REST claims.
* UI Payslip Center dan Reports & Exports masih belum dibuat.
* Full E2E memerlukan service governance, claims, payroll, edge, dan web berjalan. Pada verifikasi ini seluruh service lokal aktif.
* Semua perubahan belum di-commit atau di-push.
