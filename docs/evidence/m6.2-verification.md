## 5. Monitoring

Workflow `.github/workflows/production-monitor.yml` berjalan setiap 6 jam dan bisa dipicu manual. Workflow:

1. `pnpm warm:production`
2. `pnpm smoke:production`

Repository variables: `PROD_GOVERNANCE_URL`, `PROD_CLAIMS_URL`, `PROD_PAYROLL_URL`, `PROD_WORKER_URL`, `PROD_EDGE_URL`, `PROD_WEB_URL`. Tidak ada secret di workflow.

Dua run awal gagal di edge dengan `getaddrinfo ENOTFOUND`: variabel `PROD_EDGE_URL` memakai subdomain akun yang salah (`ridwanafazn`), sedangkan hostname yang benar adalah `ridwanafzn`. Render service pada kedua run tersebut PASS. Setelah variabel dan dokumentasi diperbaiki, run berikutnya menjadi baseline monitoring 24 jam.

Baseline: run `45816325368` (commit `2b701f1`) **PASS** dalam 27 detik, warm semua service dan smoke 15/15. Monitoring 24 jam dihitung dari run ini; status final menunggu minimal 4 run sukses (interval 6 jam).

* Tidak ada secret di repo; `.env.production.local` di-ignore Git.
* Secret production hanya ada di Render/Cloudflare/Neon/Upstash/Cloudinary dan file lokal.

* Rotasi secret setelah demo jika repository atau sesi ini dibagikan.
