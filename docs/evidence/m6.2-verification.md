## 4. Cold start free tier

Render free tier tidur saat idle. Pengukuran:

* Governance cold start: **132,4 detik**.
* Payroll cold start: >30 detik sebelum akhirnya 200.
* Setelah hangat: respons <1 detik.

Mitigasi: `pnpm warm:production` sebelum demo/smoke. Script membaca URL dari `.env.production.local` dan memberi timeout 180 detik per service.

## 5. Monitoring

Workflow `.github/workflows/production-monitor.yml` berjalan setiap 6 jam dan bisa dipicu manual. Workflow:

1. `pnpm warm:production`
2. `pnpm smoke:production`

Repository variables: `PROD_GOVERNANCE_URL`, `PROD_CLAIMS_URL`, `PROD_PAYROLL_URL`, `PROD_WORKER_URL`, `PROD_EDGE_URL`, `PROD_WEB_URL`. Tidak ada secret di workflow.

Monitoring 24 jam dihitung dari run pertama setelah workflow aktif; status final menunggu minimal 4 run sukses.
